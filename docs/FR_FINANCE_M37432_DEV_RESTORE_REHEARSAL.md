FR Finance M37432: Safe recovery rehearsal of encrypted M37431 development backup. The script creates exactly one scratch database with a fixed distinct name, verifies SHA-256, branch, cluster, original database, approved commit, disk space and explicit user confirmation. Age decrypt streams the encrypted backup directly into pg_restore under a private log; no unencrypted dump file is written. Restored account and old-development count checks must pass. A trap drops only the newly created scratch database. Existing database, identities and backup stay unchanged. A failure to clean up is reported and requires manual investigation, never force drop. This is not the final clean database and must never be imported into production. PIX, real user activation remain OFF.
